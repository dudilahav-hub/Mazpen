# מצפן EMDR: התקנה על טאבלט אנדרואיד

האפליקציה היא אתר סטטי. הקוד יושב ב-GitHub Pages; הנתונים של המטופלים לא יוצאים מהטאבלט, ונשמרים בו מוצפנים בסיסמה (AES-256, מפתח שנגזר מהסיסמה ב-PBKDF2).

## פרסום (פעם אחת, במחשב, כ-15 דקות)

1. פתח/י חשבון חינמי ב-github.com.
2. לחץ/י **New repository**. שם: `mazpen`. סוג: **Public** (בחינם Pages עובד רק עם מאגר ציבורי; מה שציבורי הוא רק הקוד, לא נתונים).
3. במאגר החדש: **Add file ← Upload files**, וגרור/י את כל הקבצים מהתיקייה הזו: `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`. ואז **Commit changes**.
4. **Settings ← Pages**. תחת Source בחר/י **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, ו-**Save**.
5. אחרי דקה-שתיים הכתובת תופיע שם, בצורה: `https://<שם-המשתמש>.github.io/mazpen/`

## התקנה על הטאבלט

1. פתח/י את הכתובת ב-Chrome.
2. תפריט ⋮ ← **התקנת אפליקציה** (או "הוספה למסך הבית").
3. פתח/י מהאייקון, ובחר/י סיסמה. **סיסמה שנשכחה = נתונים שאבדו.** רשום/י אותה במקום בטוח שאינו הטאבלט.
4. מומלץ להתחיל במטופלת לדוגמה, לעבור פגישה שלמה, ורק אז לפתוח תיק אמיתי.

## גיבוי לכרטיס הזיכרון

- פעם אחת: Chrome ← ⋮ ← הגדרות ← הורדות ← **מיקום ההורדות ← כרטיס SD**.
- באפליקציה: הגדרות וגיבוי ← **גיבוי עכשיו**. הקובץ `mazpen-backup-….json` מוצפן באותה סיסמה.
- האפליקציה תזכיר אם עברו 7 ימים מהגיבוי האחרון. מומלץ לגבות בסוף כל יום עבודה.

## חשוב לדעת

- **מחיקת נתוני האתר ב-Chrome, או הסרת האפליקציה, מוחקות את התיקים מהטאבלט.** הגיבוי הוא מה שמגן מפני זה.
- הטאבלט עצמו צריך נעילת מסך (קוד או טביעת אצבע).
- נעילה אוטומטית: אחרי 10 דקות ללא נגיעה (אפשר לשנות), וגם אחרי שתי דקות ברקע. פגישה פתוחה נשמרת ואפשר להמשיך אותה אחרי הפתיחה.
- האפליקציה עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה.
- עדכון גרסה: מעלים את הקבצים החדשים לאותו מאגר (Upload files, מחליפים את הקיימים). הטאבלט יקבל את העדכון בפתיחה השנייה אחרי ההעלאה. הנתונים לא נפגעים.
- חובות שמירת רשומות ואבטחת מידע חלות על המטפל/ת; כדאי לוודא את הדרישות מול גורם מוסמך.
